# Phase 6 — UI Design Contract

> Visual and interaction contract for the Astro demo site with React playground island. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (Astro scoped styles + vanilla CSS variables per D-09) |
| Icon library | none (sun/moon toggle uses inline SVG, fallback "?" is plain text) |

**Font stacks (exact values):**
- Body: `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Grid item internal padding, input padding-block |
| md | 16px | Default element spacing, input padding-inline, card padding |
| lg | 24px | Section internal padding, playground grid gap |
| xl | 32px | Section margin between content blocks |
| 2xl | 48px | Major section breaks (hero to playground, playground to why) |
| 3xl | 64px | Page top/bottom padding |

Exceptions: Grid items use 44px minimum touch target for the favicon display area (closest multiple of 4 to 44 is 44 itself -- exception to pure 8-point scale for accessibility).

## Typography

| Role | Size | Weight | Line Height | Font Stack |
|------|------|--------|-------------|------------|
| Body | 16px | 400 (regular) | 1.5 | system font stack |
| Label | 14px | 400 (regular) | 1.4 | system font stack |
| Heading | 20px | 700 (bold) | 1.2 | monospace stack |
| Display | 32px | 700 (bold) | 1.1 | monospace stack |

**Weight rationale:** 2 weights only -- 400 (regular) for body text and labels, 700 (bold) for headings and display. The size difference between Heading (20px) and Display (32px) provides sufficient visual hierarchy without a third weight.

**Usage map:**
- Display: Hero tagline only ("Display any website's favicon")
- Heading: Section titles ("Why", "Install"), playground label ("Try any domain")
- Body: Feature bullets, descriptions, install instructions
- Label: Domain labels under favicons in grid, input placeholder, advanced panel labels, code preview line content

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Page background |
| Secondary (30%) | `#f5f5f5` | Playground container, code preview background, advanced panel, input background |
| Accent (10%) | `#0066ff` | See reserved list below |

| Text muted | `#666666` | Domain labels, descriptions, placeholders |
| Border | `#e0e0e0` | Input borders, card borders, dividers |
| Code background | `#f0f0f0` | Code preview block |
| Destructive | not applicable | No destructive actions in this phase |

### Dark Theme

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d0d0d` | Page background |
| Secondary (30%) | `#1a1a1a` | Playground container, code preview background, advanced panel, input background |
| Accent (10%) | `#4d9fff` | See reserved list below (lighter shade for contrast on dark) |
| Text primary | `#e5e5e5` | Headings, body text |
| Text muted | `#999999` | Domain labels, descriptions, placeholders |
| Border | `#333333` | Input borders, card borders, dividers |
| Code background | `#1e1e1e` | Code preview block |

**Accent reserved for (exhaustive list):**
1. "Try it on StackBlitz" link text
2. GitHub repo link text
3. npm page link text
4. Input field focus ring (2px solid accent)
5. "Show Advanced" / "Hide Advanced" toggle text
6. Badge text (npm, bundle size) when hovered

**Accent is NOT used for:** headings, body text, borders at rest, background fills, the favicon grid items, or the install code snippet.

### CSS Variable Implementation

All colors implemented as CSS custom properties on `:root` (light) and `:root.dark` (dark). Theme toggle sets/removes `dark` class on `<html>`. Inline `is:inline` script in `<head>` prevents FOUC by reading localStorage/system preference before first paint.

### Max Width

- Page content: `640px` max-width, centered with `margin: 0 auto`
- This matches a developer-tool aesthetic (narrow, readable, focused)

### Responsive Behavior

| Breakpoint | Favicon Grid | Layout Changes |
|------------|-------------|----------------|
| >= 640px (desktop) | 4 columns | Full layout as diagrammed above |
| 480-639px (tablet) | 3 columns | Same structure, grid reflows |
| < 480px (mobile) | 2 columns | Same structure, grid reflows. Padding reduces to `md` (16px) |

Grid uses CSS `auto-fill` with `minmax(120px, 1fr)` -- no explicit breakpoints needed, grid reflows naturally.

## Favicon Grid Contract

### Pre-filled Domains (8 items)

| Domain | Why Chosen |
|--------|-----------|
| github.com | Recognizable octocat favicon, developer audience |
| google.com | Universally known "G" favicon |
| stackoverflow.com | Developer audience, distinctive orange icon |
| npmjs.com | Directly relevant -- this is an npm package |
| twitter.com | Well-known bird/X icon |
| reddit.com | Recognizable snoo icon |
| dev.to | Developer audience, bold "DEV" favicon |
| this-domain-does-not-exist-xyz.com | Intentionally triggers fallback -- demonstrates the library's key feature |

### Grid Item Layout

Each grid item is a vertical stack:
- Favicon: `SiteIcon` component at current `size` (default 32px), centered
- Domain label: Below favicon, `14px` Label style, muted text color, `text-overflow: ellipsis` with `overflow: hidden`, `max-width: 120px`
- Internal padding: `sm` (8px) all sides
- Background: none (transparent, sits on secondary surface of playground container)
- On user input: the user's domain prepends to the grid as the first item. Default domains remain after it.

### Fallback Display

- Character: `?`
- Styling: `32px` font-size (matches default favicon size), `line-height: 1`, centered in a `32x32` area
- Color: text-muted (`#666666` light / `#999999` dark)
- Container: `display: inline-flex; align-items: center; justify-content: center; width: {size}px; height: {size}px`

## Interaction Contract

### Domain Input

| Property | Value |
|----------|-------|
| Type | `<input type="text">` |
| Width | 100% of playground container |
| Padding | `sm` (8px) block, `md` (16px) inline |
| Border | 1px solid `--border` |
| Border radius | 4px |
| Focus | 2px solid `--accent` outline, no default browser outline |
| Font | Body (16px, system font) -- prevents iOS zoom on focus |
| Debounce | None. SiteIcon handles domain changes internally. Update state on every keystroke. |
| Behavior | User types domain. Grid prepends the typed domain as first item. Code preview updates live (D-07). |

### Advanced Panel

| Property | Value |
|----------|-------|
| Default state | Collapsed (hidden) |
| Toggle | Text button: "Show Advanced" / "Hide Advanced" in accent color |
| Animation | `max-height` transition, 200ms ease-out. Collapsed: `max-height: 0; overflow: hidden`. Expanded: `max-height: 200px` (generous ceiling). |
| Strategy control | `<select>` with three options: lazy, eager, hidden |
| Size control | `<input type="range">` min=16 max=128 step=1, with "Size: {N}px" label |
| Effect | Changing strategy or size updates all grid items and the code preview simultaneously |

### Code Preview

| Property | Value |
|----------|-------|
| Background | `--code-bg` (`#f0f0f0` light / `#1e1e1e` dark) |
| Font | Monospace stack, `14px` (Label size) |
| Padding | `md` (16px) |
| Border radius | 4px |
| Border | 1px solid `--border` |
| Content | Live-updating JSX snippet showing import + component usage with current props |
| Syntax highlighting | CSS-only manual spans: `.token-keyword` (blue/cyan), `.token-string` (green/orange), `.token-tag` (red/coral), `.token-attr` (purple/violet). 4 token classes, no JS highlighter. |
| Overflow | `overflow-x: auto` with horizontal scroll if line exceeds container |

**Code preview template (updates with current state):**
```
import { SiteIcon } from 'react-site-icon';

<SiteIcon
  domain="{currentDomain}"
  {sizeIfNot32}
  {strategyIfNotLazy}
  fallback={<span>?</span>}
/>
```

- `size` prop line omitted when value is 32 (the default)
- `strategy` prop line omitted when value is "lazy" (the default)
- `domain` value reflects what the user typed, or "github.com" if input is empty

### Theme Toggle

| Property | Value |
|----------|-------|
| Placement | Top-right of page header |
| Icon | Sun SVG (in dark mode, clicking switches to light) / Moon SVG (in light mode, clicking switches to dark) |
| Size | 20px icon within a 32px touch target |
| Implementation | Pure Astro component with inline `<script>`. Toggles `dark` class on `<html>`, persists to localStorage. NOT a React component. |
| Transition | `background-color` and `color` transitions on `body` use `transition: background-color 150ms ease, color 150ms ease` for smooth theme switch |

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
| Theme toggle button | `aria-label="Switch to dark theme"` / `aria-label="Switch to light theme"` (updates with state) |
| Domain input | `<label>` element associated via `htmlFor`/`id`, or `aria-label="Domain to preview"` |
| Favicon grid | Each grid item is a `<div>` (not interactive). No ARIA role needed -- purely visual display. |
| Fallback "?" | `aria-hidden="true"` on the fallback span (SiteIcon handles `alt` on the img) |
| Code preview | `<pre><code>` semantic markup. `aria-label="Generated code example"` on the `<pre>` |
| Advanced panel | Toggle button has `aria-expanded="true"/"false"`. Panel has `id` referenced by `aria-controls` on the button. |
| Color contrast | All text meets WCAG 2.1 AA (4.5:1 minimum). Verified: `#1a1a1a` on `#ffffff` = 16.6:1. `#666666` on `#ffffff` = 5.7:1. `#e5e5e5` on `#0d0d0d` = 17.4:1. `#999999` on `#0d0d0d` = 8.2:1. |
| Focus visible | All interactive elements (input, select, range, buttons, links) show visible focus indicator using `--accent` color |
