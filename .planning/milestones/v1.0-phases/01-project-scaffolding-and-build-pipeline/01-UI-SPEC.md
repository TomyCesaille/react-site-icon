# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Applicability

**This phase has no visual or interaction deliverables.**

Phase 1 produces build tooling, configuration files, and a skeleton SiteIcon component that validates the pipeline. The skeleton renders a bare `<img>` element with no styling, no design tokens, and no user-facing interactions. All output files are configuration (tsup, tsconfig, eslint, prettier, husky, changesets, package.json) or build artifacts (dist/).

The first phase requiring a visual contract is Phase 2 (Core Component), which introduces the SiteIcon component with fallback rendering states. Phase 6 (Demo Site) will require a full visual contract for the Astro landing page.

| Property | Value |

**Rationale:** This is a zero-dependency React component library. It does not use shadcn, Tailwind, or any design system. The library ships a single `<img>` element. No design system initialization is needed for the library itself. The demo site (Phase 6) may introduce Tailwind/shadcn for the landing page, but that is out of scope for Phase 1.
