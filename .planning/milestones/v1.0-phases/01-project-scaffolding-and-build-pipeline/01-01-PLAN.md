2. Create `src/SiteIcon.tsx` -- skeleton component per D-01 (domain prop, renders img with Google faviconV2 URL, no detection logic, no state):

```tsx
import type { CSSProperties, ReactNode } from 'react';

export interface SiteIconProps {
  /** Domain to fetch the favicon for (e.g. "github.com") */
  domain: string;
  /** Requested favicon size in pixels */
  size?: number;
  /** Content to render when no favicon is available */
  fallback?: ReactNode;
  /** CSS class for the img element */
  className?: string;
  /** Inline styles for the img element */
  style?: CSSProperties;
  /** Alt text for the favicon image */
  alt?: string;
}

const buildUrl = (domain: string, size: number): string =>
  `https://t1.gstatic.com/faviconV2?client=SOCIAL&type=FAVICON&fallback_opts=TYPE,SIZE,URL&url=http://${domain}&size=${size}`;

export function SiteIcon({
  domain,
  size = 32,
  className,
  style,
  alt = '',
}: SiteIconProps): React.JSX.Element {
  return (
    <img
      src={buildUrl(domain, size)}
      alt={alt}
      width={size}
      height={size}
      className={className}
      style={style}
    />
  );
}
```

This skeleton validates: JSX compilation (tsx to js), React externalization (import type only -- no runtime React in bundle), TypeScript interface export (SiteIconProps exported for .d.ts generation), and realistic bundle size measurement (actual component code, not an empty placeholder). The `fallback` prop is declared in the interface but not used in the skeleton -- Phase 2 implements the detection logic.

<threat_model>
## Trust Boundaries

No trust boundaries in this phase. This is build tooling and project scaffolding -- no user input processing, no network endpoints, no authentication. The skeleton component renders an `<img>` tag with a domain prop; input sanitization is a Phase 2 concern.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | Google faviconV2 CDN URL | accept | URL is hardcoded to Google's CDN; no user-controlled protocol or host. Domain prop only fills the `url` query parameter. Full URL construction security addressed in Phase 2. |
| T-01-02 | Tampering | npm package contents | mitigate | `"files": ["dist"]` ensures only build output is published; no source code, no .env, no config files shipped to npm. |
| T-01-03 | Information Disclosure | Source code in npm package | mitigate | `"files": ["dist"]` prevents source, tests, and planning artifacts from being included in the published package. |
</threat_model>
