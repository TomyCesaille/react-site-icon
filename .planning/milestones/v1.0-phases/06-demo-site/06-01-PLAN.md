## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Google CDN | Favicon images loaded from external CDN (inherent to library) |
| User input -> SiteIcon domain prop | Domain string from text input passed to component |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-06-01 | Tampering | Domain input in Playground | accept | React escapes all rendered strings. SiteIcon normalizes domain via URL constructor. No dangerouslySetInnerHTML. Input is purely client-side with no server processing. |
| T-06-02 | Information Disclosure | Google CDN requests | accept | The library's core purpose is loading favicons from Google CDN. No user PII is sent. Domain names are not sensitive data. |
| T-06-03 | Spoofing | Third-party badge images (shields.io) | accept | Badges are decorative. Even if shields.io serves wrong data, no security impact. Standard practice for OSS READMEs/sites. |
</threat_model>
