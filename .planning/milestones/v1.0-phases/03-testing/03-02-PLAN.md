2. **Add `test:exports` script to package.json** (per D-07):

In the `"scripts"` section of package.json, add a new entry:
```json
"test:exports": "attw --pack ."
```

Place it after the existing `"test:watch"` entry. The full scripts section should be:
```json
"scripts": {
  "build": "tsup",
  "typecheck": "tsc --noEmit",
  "lint": "eslint src/",
  "lint:fix": "eslint src/ --fix",
  "format": "prettier --write src/",
  "format:check": "prettier --check src/",
  "test": "vitest run",
  "test:watch": "vitest",
  "test:exports": "attw --pack .",
  "prepare": "husky"
}
```

**Important**: `attw --pack .` internally runs `npm pack`, which creates a tarball from the `"files": ["dist"]` directory. This means `dist/` must exist with build output. The script is designed to be run AFTER `npm run build`. In CI (Phase 4), the sequence will be: build -> test -> test:exports.

3. **Verify by running build then attw**:
```bash
npm run build && npm run test:exports
```

Expected output: attw analyzes all resolution modes (node10, node16, bundler) for both ESM and CJS entrypoints and reports no errors. The `exports` field in package.json (with types-first ordering, separate import/require conditions) was set up correctly in Phase 1.
