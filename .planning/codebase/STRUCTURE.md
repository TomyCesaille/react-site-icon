## Directory Purposes

**`src/`:**
- Purpose: All library source code -- component implementation and tests
- Contains: 3 files total (index.ts, SiteIcon.tsx, SiteIcon.test.tsx)
- Key constraint: Everything in this directory contributes to the < 1KB bundle size limit

**`dist/`:**
- Purpose: tsup build output shipped to npm
- Generated: Yes (`npm run build`)
- Committed: No (gitignored)
- Contents: ESM, CJS, type declarations, sourcemaps

**`docs/`:**
- Purpose: Marketing demo site with interactive playground
- Separate npm project with its own `package.json`, `node_modules/`, `package-lock.json`
- Links to library via `"react-site-icon": "file:.."`
- Deployed to GitHub Pages via `withastro/action@v6`

**`examples/basic/`:**
- Purpose: Standalone example showing how consumers use the library
- References `react-site-icon@latest` from npm (not local link)
- Not part of CI -- documentation/reference only

**`.changeset/`:**
- Purpose: Version management config for Changesets
- `config.json` configures public access, main branch, GitHub changelog format

**`.github/workflows/`:**
- Purpose: Three GitHub Actions workflows for CI, demo deploy, and npm release

**`.husky/`:**
- Purpose: Git hooks directory managed by Husky v9
- `pre-commit` runs `npx lint-staged`

**`.planning/`:**
- Purpose: GSD workflow artifacts (project plans, milestones, codebase analysis)
- Not shipped to npm (not in `"files"` field)

## Naming Conventions

**Files:**
- Component: PascalCase (`SiteIcon.tsx`)
- Tests: PascalCase with `.test.tsx` suffix, co-located (`SiteIcon.test.tsx`)
- Barrel exports: `index.ts`
- Config files: lowercase with tool name (`tsup.config.ts`, `vitest.config.ts`, `eslint.config.mjs`)
- Astro files: PascalCase for components (`Playground.tsx`, `ThemeToggle.astro`), lowercase for pages (`index.astro`)

**Directories:**
- Lowercase: `src/`, `dist/`, `docs/`, `examples/`
- Astro convention: `pages/`, `components/`, `layouts/`, `styles/`, `public/`

## Where to Add New Code

**New component prop or feature:**
- Implementation: `src/SiteIcon.tsx`
- Types: Update `SiteIconProps` interface in `src/SiteIcon.tsx`
- Exports: Update `src/index.ts` if adding new exported types
- Tests: `src/SiteIcon.test.tsx` (add new `describe` block)

**New exported utility or type:**
- Implementation: Create new file in `src/` (e.g., `src/utils.ts`)
- Exports: Add to `src/index.ts`
- Tests: Create co-located test file (e.g., `src/utils.test.ts`)

**Demo site changes:**
- Pages: `docs/src/pages/`
- React components: `docs/src/components/` (use `client:visible` or `client:load` for hydration)
- Styles: `docs/src/styles/global.css` for global styles, scoped `<style>` blocks in Astro files
- Static assets: `docs/public/`

**New example:**
- Directory: `examples/{name}/`
- Follow `examples/basic/` pattern (Vite + React, `react-site-icon@latest` dependency)

**CI workflow changes:**
- Directory: `.github/workflows/`

## Special Directories

**`dist/`:**
- Purpose: Build output
- Generated: Yes (by `npm run build` / tsup)
- Committed: No (gitignored)
- Shipped to npm: Yes (via `"files": ["dist"]`)

**`docs/dist/`:**
- Purpose: Astro build output for demo site
- Generated: Yes (by `npm run build --prefix docs`)
- Committed: No (gitignored in `docs/.gitignore`)

**`node_modules/`:**
- Exists at root level and in `docs/`
- Committed: No

**`coverage/`:**
- Generated by Vitest when run with coverage flag
- Committed: No (gitignored)
